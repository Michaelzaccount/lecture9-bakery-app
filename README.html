Bakery orders

Use the dashboard to turn Instagram requests into a pickup schedule. Recording a message puts it in the review queue. Accepting it updates the schedule and sales.

Start the app

For the updated app launched in this project session, open the dashboard on port 8002.

  1. To start a fresh session on Mac, find Lecture 9_Tools in Finder. Control-click the folder and choose New Terminal at Folder (it may appear under Services).
  2. Type python3 app.py and press Return. Keep Terminal open. The app uses Python 3.9 or later and the Python standard library.
  3. Open the default dashboard on port 8000. To stop a server you started, press Control + C in its Terminal window. Saved orders remain in the project folder.

Manage requests

  1. Choose the day the DM arrived. Set Working date and select View day. The dashboard starts on Monday, November 23, 2026. Switching dates lets you revisit pending decisions.
  2. Record the request. Expand Record an Instagram DM, enter the customer name, request type and pickup date, then select Save for review. For an order or change, enter one product and its full requested quantity. For changes and cancellations, use the same customer name and pickup date as the accepted order. The app needs exactly one match.
  3. Review the decision. Find a new order under New requests or Incompatible orders. Changes and cancellations have their own section. Select Accept request or Reject request. Each blocked request shows the reason. A change replaces the existing quantity and product. A cancellation frees the booked time and removes the sale.
  4. Check pickups. The selected day lists accepted pickups at 5 PM. Upcoming days shows each day’s orders, hours and helper booking. Expand Decided requests to see decisions for messages received on the selected day.

Using the lecture DMs? The seven supplied daily files cover November 23–29, 2026. The app imports them on first setup. Fetch new DMs rereads the selected day’s file and skips messages already present with the same date and text. For messages from your Instagram account, use manual entry.

Accept all and go to next day processes pending requests, including changes and cancellations, in saved order. It checks capacity after each acceptance. Requests that fail a check stay pending on their original day. You can advance each day once.

Each pickup day has eight baking hours. To book one helper, select +4 h · $100 under that pickup day. This records a $100 cost and raises capacity to twelve hours. Review the pending request again after booking.

Orders, changes and cancellations require two calendar days between the DM date and pickup. Helper bookings use the selected working date for the same check. For example, a Monday request can qualify for Wednesday pickup. With seven hours already booked, a Wednesday cake would bring the total to nine hours and require a helper.

After helpers is the value of all active accepted orders minus all helper booking costs. Ingredient and other expenses are outside this calculation.

Implementation and storage

app.py · web server and decision rules
Python serves the dashboard on the local loopback address. A GET request renders HTML from SQLite. Forms submit POST requests to record messages, make decisions and book helpers. Each action runs in a database transaction and redirects back to the dashboard after success. The server rechecks notice, matching orders and capacity before accepting a request.
bakery.db · saved state
The messages table tracks the received date, request details and decision. The orders table holds accepted orders, with an active flag for cancellations. The helpers table allows one booking per pickup date. The metadata table records initial import and which days have advanced.
existing_orders.csv and InstagramOrders_*.html · starting data
On first setup, the app loads existing orders from the CSV and extracts message paragraphs from the daily HTML files. Later launches reuse the database. To back up your work, stop running instances and copy bakery.db. Use a copy of the database for tests.
